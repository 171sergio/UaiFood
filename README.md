# Uai Food - Sistema de Pedidos

Este é um sistema de pedidos e gerenciamento de restaurantes desenvolvido em C. Ele permite que clientes façam pedidos de pratos de diferentes restaurantes, enquanto os restaurantes podem gerenciar seus pratos e informações.

Funcionalidades
Para Clientes
Cadastrar cliente.

Fazer pedidos de pratos.

Ver resumo do pedido e histórico de pedidos.

Renomear ou deletar a conta.

Para Restaurantes
Cadastrar restaurantes e pratos.

Renomear ou deletar restaurantes e pratos.

Alterar preços dos pratos.
